# 拾光集发布前验收清单

更新日期：2026-09-23。

## 工程内已经完成

- 手机与折叠屏窗口采用响应式商品网格：极窄窗口单列、常规手机双列、展开态或横屏三列；表单和详情页限制最大阅读宽度。
- 主要图片已区分“可操作内容”和“装饰内容”，输入框、关闭按钮、导航与店铺入口具备明确无障碍名称。
- 登录密码键盘支持“完成”提交；地址表单在小于 360vp 时将省、市、区改为纵向排列，避免键盘与窄屏挤压。
- 页面动效使用有限次数的上浮、漂移和弹簧反馈，没有无限循环动画。
- 权限保持为仅网络访问；系统应用数据备份已关闭，避免本地登录令牌被备份迁移。
- Debug/未签名 HAP 可正常构建；消费者、购物、主题、无障碍与发布静态检查均可执行。

## 必须由开发者在发布前提供或确认

- 永久 `bundleName`、真实 `vendor`、应用版本号。当前 `com.example.myapplication` 和 `example` 只是开发期占位，发布后不宜再更换包名。
- HarmonyOS 发布证书、Profile 与签名配置。证书属于个人/企业敏感凭据，只能在本机 DevEco Studio 或安全 CI 中配置，不能提交仓库。
- 正式 HTTPS 服务地址、隐私政策链接、用户协议、应用商店截图、分类与备案信息。
- 至少一台真机及目标折叠屏/模拟器，用于屏幕阅读器、大字体、软键盘遮挡、横竖屏切换、开合连续性和系统返回手工验收。

## 本地发布检查

```powershell
node scripts/check-release.cjs
node scripts/check-accessibility.cjs
```

构建成功只证明工程可以产出 HAP，不代表应用已签名、已完成真实设备体验验收或具备上架资格。
